# Translating usai-web

Locales: **en** (source, served at `/`) and **id** (Bahasa Indonesia, served at `/id/`).

## Where strings live

- `src/i18n/en.ts`: the English source. Its shape defines the `Dict` type.
- `src/i18n/id.ts`: typed `Dict`. A missing or extra key is a type error in `pnpm check`.
- Numbers, code and runtime names are not translated. They come from `src/data/`.

## Markup inside strings

- `[[key]]` or `[[key|label]]` marks a glossary term. Translate the **label**, keep the **key**.
- Use a lower-case label mid-sentence.
- `**bold**` and `` `code` `` work as expected.

## Terminology (id)

Keep common engineering words in English, as Indonesian developers use them: request, runtime, deploy, handler, pool, queue, task, cron, WebSocket, benchmark, throughput. Translate the concepts:

| English | Indonesian |
|---|---|
| lifetime | umur (lifetime) |
| ownership | kepemilikan |
| contract | kontrak |
| boundary validation | validasi batas / validasi di pintu masuk |
| quarantine | karantina |
| detached work | pekerjaan terlepas |
| execution world | execution world (keep; it is the product's term) |

- Address the reader as **kamu**.
- Use Indonesian number formatting (`73,6 jt`, `1.000`, `0,00 %`). `Intl.NumberFormat('id-ID')` handles the charts.
- The descriptor stays in English: *A workload-native application runtime*.

## Adding a locale

1. Add the code to `locales` in `src/i18n/index.ts` and to `i18n.locales` / `sitemap.i18n.locales` in `astro.config.mjs`.
2. Create `src/i18n/<code>.ts` typed as `Dict`.
3. Copy `src/pages/id/` to `src/pages/<code>/` and change `lang`.
4. Add `localeMeta` (label, `og:locale`).
5. `pnpm verify`.
